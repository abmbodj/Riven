# Riven Design Context

## Target Audience
College students preparing for exams. They use Riven daily for flashcards, study guides, and mock exams. They are time-pressured, performance-anxious, and mobile-first.

## Brand Personality
Academic gravity meets quiet confidence. Not clinical, not gamified. Like a library at midnight — focused, a little austere, occasionally warm. The aesthetic should feel like a professor designed it: serious type, restrained color, moments of earned delight (results reveal, streak milestone).

## Existing Stack
- React + Tailwind with a custom CSS variable theme system (`--claude-bg`, `--claude-accent`, etc.)
- Display font: Cormorant Garamond (serif italic for headings)
- Body font: Lora
- Mono font: used for labels, counters, metadata
- Motion: GSAP + motion/react (Framer Motion)
- Dark theme by default; glass-panel utility class for card surfaces
- Design tokens: `claude-bg`, `claude-surface`, `claude-text`, `claude-secondary`, `claude-accent`, `claude-border`

## Design Constraints
- Mobile-first, fullscreen exam UI — no nav, no sidebar during exam
- No glassmorphism overuse — glass-panel is used sparingly for depth, not decoration
- No bounce/elastic easing — use ease-out-quart or EASE.organic from utils/animations.js
- No pure black/white — always use theme tokens
- Timer must feel present but not anxiety-inducing — secondary position, not alarm-red
- Results screen should feel like getting your grade back, not a quiz completion popup

## What Makes This Unforgettable
The moment the results screen reveals — a half-second pause before the score animates in. Students should feel their stomach drop slightly, then relief or determination. That emotional beat is the design target.
