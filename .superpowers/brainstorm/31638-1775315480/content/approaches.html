Three Simplification Approaches

All preserve existing functionality. Pick the one that feels right.

A

Smart Default + Progressive Disclosure

Recommended. The app picks the best session for you and surfaces it as a single prominent CTA ("Start Study Session"). Full Session / Quick / Quiz Me collapse into a secondary "Change session type" link below. Entry screen shrinks from a decision wall to a one-tap launch pad. During studying, the desktop rail is simplified and mobile sheets get labeled bottom-nav tabs instead of mystery icons. Dashboard gets a single "Study Again" button as the primary action.

Pros

  • Fastest path to studying
  • Minimal code changes
  • Power users still have full access

Cons

  • Requires a smart "recommended session" algorithm
  • May feel opinionated to advanced users
B

Guided First-Run + Persistent Simplicity

First time a user opens a guide, they get a short inline onboarding card ("Here's how this works — 3 steps"). After that, the entry screen is simplified permanently. Mobile gets a persistent bottom bar with Home / Sections / Note labels (replacing hidden icon buttons). Dashboard cards are collapsed by default, expand on tap.

Pros

  • Teaches the mental model once
  • Clean experience after onboarding

Cons

  • Onboarding adds scope
  • Still has mode-switching complexity underneath
C

Merged Entry + Study Flow

Eliminate the Entry screen as a separate stop. Opening a guide goes directly into the first section (or the weakest section if returning). Session type becomes a persistent top-bar toggle, not a pre-session gate. Quiz and Dashboard remain as separate destinations reachable from a simplified action bar. The "mode" concept disappears from the user's mental model.

Pros

  • Fewest taps to studying
  • Most coherent single-flow experience

Cons

  • Biggest structural change
  • Loses explicit session framing (some users like the ritual)
