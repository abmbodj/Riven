Study Dock — Context-Aware Options

All use the existing floating pill dock. The dock swaps its content when you're in a study session, then restores to default when you leave. Which tab layout feels right?

Study Tabs Replace Default Tabs

While studying, the top row of the dock becomes Sections · Details · Note and the icon row becomes the section nav (Prev / current count / Next). Leaving the guide restores Rooms / Inspiration / Profiles. Clean, no extra UI.
