3 Approaches to the Ultimate Study Guide

Each builds on what already exists — pick the direction that feels right

A

Session-First Overhaul

Focus: Transform how students study, leave content gen mostly as-is for now.

  • Quick-session mode ("I have 10 min")
  • Forced active recall — no passive scrolling
  • Smooth mobile swipe-through flow
  • Weakness tracking with hybrid scheduling
  • Post-gen editing deferred to later
Best if: The biggest pain is how studying feels, not what's in the guide
B

Content-First Overhaul

Focus: Fix what the AI generates + let students edit it. Better raw material.

  • Redesigned AI prompt — tighter, more focused sections
  • Inline section editor (rename, rewrite, delete)
  • Add/remove key terms & answer points
  • Post-gen quality pass UI
  • Smart session deferred to later
Best if: Students give up on guides because the AI output is too unreliable
C

Full "Study Coach" Overhaul ⭐ Recommended

Focus: All three systems together — smarter content, smarter sessions, smarter guidance.

  • Better AI prompt + inline section editing
  • Quick-session mode with auto-selected material
  • Swipe-through mobile study flow
  • Hybrid spaced rep: AI suggests order, you override
  • Weakness dashboard per guide
  • "Just quiz me" rapid-fire mode
Best if: You want students to feel the improvement from day one, top to bottom

My recommendation

C — but broken into two phases. Phase 1 ships the session + mobile experience (fastest user-felt impact). Phase 2 ships editing + hybrid scheduling. Both specs can be written together so the architecture is consistent.
