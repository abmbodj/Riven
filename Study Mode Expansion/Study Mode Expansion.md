# Study Mode Expansion  
  
I want to expand rivens study menu/feature. Currently the menu takes you to the flashcards which i want to keep this menu but i want to turn study into a dashboard that has study guides, mock exam, flashcards, and notes.  
  
Flashcards should just take you to what the current study is which is the decks menu.   
  
Mock Exam is a new feature that allows users to upload notes or studies guides to create a mock exam / test.   
  
Study guides should allow users to generate study guides using their notes. Additionally these study guides can be used to create mock exams and flashcard decks.   
  
Notes should be a menu where users can see their vault of notes. Each note can be linked to a class. In the ClassView menu should now have a notes section. Notes can be used to make flashcards, study guides, or mock exams. In the future, I want to add a feature that allows users to record audio and then AI turns that audio into great notes.
