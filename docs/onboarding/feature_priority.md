# Feature priority for onboarding narrative

1. **Audio → notes** — primary hook; step 3 drives to [`/note/new`](../../client/src/pages/NoteEditor.jsx) (mic + enhancement path).
2. **Syllabus / materials** — differentiator; step 4 drives to [`/create`](../../client/src/pages/CreateDeck.jsx) with `?focus=syllabus` (AI / file ingest pre-selected).
3. **Flashcards & exams** — outcome loop; step 5 drives to [`/decks/library`](../../client/src/pages/DeckLibrary.jsx) for first study session.

Guides and groups are out of the critical path for v1 onboarding.
